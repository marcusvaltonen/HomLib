.. _installation_users:

Step-by-step installation for users
===================================

Pre-built python wheels are available on PyPI for the latest versions of
Windows, macOS, and Linux. Simply install them using:

.. code-block::

       pip install homlib

Pre-built wheels include the **LOMSAC** backend.
The optional backends (GC-RANSAC, MAGSAC++, SupeRANSAC) are available when
building from source on Linux or macOS — see :ref:`backend_availability` for
details.
